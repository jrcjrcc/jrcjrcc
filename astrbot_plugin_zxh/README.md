# 真心话大冒险 AstrBot 插件

[![AstrBot Plugin](https://img.shields.io/badge/AstrBot-Plugin-green.svg)](https://github.com/AstrBotDevs/AstrBot)
[![License](https://img.shields.io/badge/License-AGPL--3.0-blue.svg)](LICENSE)

一个基于AstrBot框架的趣味互动插件，为群聊提供经典的真心话大冒险游戏体验。

## ✨ 功能特性

- 🎮 **经典游戏玩法** - 支持真心话、大冒险两种模式
- 🔄 **智能抽签系统** - 四种抽签结果，概率均衡
- 👥 **群友互动** - 支持指定群友提问功能
- 📊 **积分排行榜** - 自动记录玩家积分和游戏历史
- ⚡ **实时状态管理** - 游戏状态实时更新和保存
- 🎯 **丰富的题库** - 包含15+真心话问题和15+大冒险挑战

## 📦 安装指南

### 前提条件
- AstrBot 框架已部署并运行正常

### 安装步骤

1. **下载插件文件**
1. **重启 AstrBot 服务**

3. **验证安装**
- 在群聊中发送 `/真心话大冒险 帮助`
- 查看是否显示帮助信息

## 🚀 使用方法

### 基本命令

| 命令   | 功能       | 示例                 |
| ------ | ---------- | -------------------- |
| `开始` | 开始新游戏 | `/真心话大冒险 开始` |
| `抽签` | 参与抽签   | `/真心话大冒险 抽签` |
| `结算` | 查看排行榜 | `/真心话大冒险 结算` |
| `状态` | 游戏状态   | `/真心话大冒险 状态` |
| `结束` | 结束游戏   | `/真心话大冒险 结束` |
| `帮助` | 查看帮助   | `/真心话大冒险 帮助` |

### 游戏流程

1. **开始游戏**

2. /真心话大冒险 开始

  
   2. **玩家抽签**
   

   /真心话大冒险 抽签

   
   3. **根据抽签结果执行**
   - 🎯 中签：回答真心话或完成大冒险
   - 🛡️ 未中：安全通过，获得积分
   
   4. **查看排名**
   

   /真心话大冒险 结算

   
   ## ⚙️ 配置说明
   
   ### 抽签概率配置
   插件支持四种抽签结果，默认概率各为25%：
   - AI提问真心话
   - AI提问大冒险  
   - 指定群友提问
   - 安全通过
   
   ### 题库自定义
   可以修改插件文件中的题库内容：
   

   python

   self.truth_questions = [

   "你的自定义真心话问题1",

   "你的自定义真心话问题2",

   \# ... 更多问题

   ]

   self.dare_challenges = [

   "你的自定义大冒险挑战1",

   "你的自定义大冒险挑战2",

   \# ... 更多挑战

   ]

   ## ❓ 常见问题
   
   ### Q: 插件安装后不生效怎么办？
   A: 请检查：
   1. AstrBot服务是否正常运行
   2. 插件文件是否放在正确的plugins目录
   3. 是否重启了AstrBot服务
   
   ### Q: 如何自定义题目？
   A: 直接修改插件文件中的`truth_questions`和`dare_challenges`列表。

   ### Q: 游戏数据是否持久化？
   A: 当前版本游戏数据存储在内存中，重启后清空。
   
   ### Q: 支持哪些消息平台？
   A: 支持所有AstrBot支持的平台，包括QQ、QQ频道、Telegram、微信等 [1,2](@ref)。
